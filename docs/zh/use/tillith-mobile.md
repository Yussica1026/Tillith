# Tillith 客户端

Tillith 直接使用本仓库的 Python 核心，客户端位于 `mobile/`，采用 React、TypeScript、Vite 和 Capacitor。界面按可用宽度自适应，供手机、平板与桌面使用；平台能力通过原生桥接接入。

## 运行位置

连接设置提供两种模式：

| 模式 | 核心运行位置 | 当前状态 |
| --- | --- | --- |
| 云端核心 | 指定的 Tillith 服务器 | 已通过本机真实核心验证连接、会话、`/help`、附件与历史持久化；本轮没有部署公共云服务。 |
| 手机内置核心 | Android 应用内的 Python 运行时 | 已在桌面环境验证嵌入启动入口、鉴权与身份持久化；Android 原生依赖及 APK 尚未通过运行验证。 |

浏览器不能启动手机内置核心；没有可用原生桥接时，界面会明确显示不可用。`127.0.0.1` 始终指当前设备，本机开发入口不能直接作为另一台手机的服务器地址。

## 本机启动

在仓库根目录运行。当前开发环境使用 `.runtime/core` 中的 Python 3.12 与完整核心依赖，运行数据保存在 `.runtime/local`。先构建客户端，再启动核心：

```powershell
cd mobile
npm.cmd ci
npm.cmd run build
cd ..
.runtime\core\Scripts\python.exe scripts/tillith_dev.py start
```

打开 `http://127.0.0.1:6195`。该入口由真实 Python 核心直接提供 `mobile/dist`，默认只监听本机；Windows 后台进程隐藏运行。启动器关闭指标上传与运行追踪，并阻止通过 WebUI 自行升级或重启核心。公开模型元数据的启动查询没有独立关闭配置；查询失败不阻止核心启动。

检查、停止和查看帮助：

```powershell
.runtime\core\Scripts\python.exe scripts/tillith_dev.py status
.runtime\core\Scripts\python.exe scripts/tillith_dev.py stop
.runtime\core\Scripts\python.exe scripts/tillith_dev.py --help
```

修改客户端后重新执行 `npm.cmd run build`。运行目录、凭据和测试数据均在 Git 忽略范围内；启动器只显示凭据文件的位置。

## 连接与使用

在连接设置中选择“云端核心”，填写 Tillith 服务地址和具有 `chat`、`file` 权限的 API Key。客户端通过 `/api/v1/tillith/profile` 获取已有鉴权身份，再使用核心的会话、WebSocket 和文件接口；不需要为客户端创建另一套用户系统。

连接后可新建会话、发送消息或附件，返回会话列表查看历史并重命名会话。未配置模型时，可发送 `/help` 验证内置指令的真实往返。普通模型回复需要另外配置提供商；本轮未接入或验证外部 LLM，不把内置指令回复当成模型调用结果。

## 聊天界面

会话列表支持名称搜索、置顶、星标、归档和消息正文搜索。会话标记保存在核心，草稿与模型选择按核心和账号保存在本机；浏览器刷新后需要重新输入连接密钥，连接到原身份后恢复草稿。

聊天页上方可选择配置、模型和是否流式显示。消息的“操作”菜单支持修改最后一条用户消息并重答、重新回答、版本预览与切换、从完整回复创建分支以及删除整轮。版本切换同时恢复显示内容和模型上下文。更新前由旧 WebSocket 生成、没有检查点的消息仍可阅读和复制，不支持这些上下文操作。

聊天使用 Tillith 的检查点 WebSocket 接口。断线后按运行 ID 续接，快照替换已有内容，不重新发送付费请求；运行已结束时读取持久化历史。停止会等待部分回复落盘。用量缺失时显示“未提供”。

回复支持 Markdown 表格、列表、引用与代码块，可复制完整回复或单个代码块；上传的图片可在应用内放大预览。向上阅读历史时，新片段不会强制滚动到底部，点击“回到最新”恢复跟随。输入框随内容增高，Ctrl/Cmd + Enter 发送消息，并避开输入法组合输入。

附件入口提供拍照、相册和文件选择；超过 2 MiB 的 JPEG、PNG、WebP 在本机按最长边 2048 像素压缩，仅在体积减小时采用压缩结果。动画 GIF 保留原文件。会话菜单可导出正文 Markdown 或 JSON；导出记录含附件名称，不包含附件二进制、思考内容、工具轨迹或连接凭据。Android 使用系统保存位置选择器。

“更多”提供深浅色、水色、薄荷、丁香、腮红主题以及字号、消息间距、代码外观设置。外观保存在当前设备。

本批已通过隔离核心和合成模型的浏览器操作链：发送、修改、重答、版本恢复、分支、整轮删除、搜索、标记持久化、草稿恢复、导出和断线续接。合成测试不代表外部模型兼容性；Android 后台恢复、相机/相册和系统文件保存仍需目标手机验收。

## 线路与服务器配置

“更多 → 线路与模型”使用单独的管理 API Key（`provider` 权限），提供服务与模型的新增、编辑、删除、启停、模型拉取和实际连接测试。协议表单读取核心 schema；模型参数写入各线路的 `custom_extra_body`。已有凭据只显示“已配置”，留空保留，填写新值才替换。

连接设置可保存多套云端或本机配置。聊天和管理凭据使用不同 Android Keystore 槽位；旧版单槽凭据迁入新槽成功后才删除旧值。浏览器只持久化配置名称和地址，密钥留在内存，刷新需重新输入。线路管理已通过本机合成提供商的真实请求和完整浏览器操作链，尚不代表所有外部协议和 Android 真机均已验收。

## 人格、世界书与记忆

从“更多 → 人格、世界书与记忆”进入管理页。人格页可维护提示词、开场白、显示名称、文件夹和新窗口默认模型，并打开已有窗口或新建窗口。聊天顶部的上下文按钮选择人格和世界书；已有消息的窗口不能直接换成人格不同的上下文，请另开窗口。世界书支持条目编辑、关键词或正则触发、常驻条目、扫描深度、优先级、角色与注入位置，以及 JSON 导入导出；已选世界书可逐个取消。

记忆页提供按人格筛选、关键词搜索、类型、星标、编辑、移入回收站和恢复。消息操作菜单中的“记为记忆”会自动关联原消息；修改、替换或删除来源后，相应记忆会标为来源失效，不再注入。聊天中的记忆召回和模型记忆工具默认关闭，需分别开启。当前使用关键词召回，尚未实现向量检索和自动摘要。“上下文来源”显示该轮实际注入的世界书条目和记忆。

聊天输入框的快捷短语按钮可保存、编辑、删除和插入常用文字；短语按核心、账号与人格保存在当前设备，插入后仍由用户发送。不同人格窗口的草稿分别保存。

会话导出菜单另外提供 JSONL“备份对话”，使用管理密钥的 `data` 权限，仅备份所选会话，与 Markdown/JSON 正文导出分开。删除当前连接配置会立即断开连接并清空当前身份界面。人格管理使用 `persona` 权限，线路管理使用 `provider` 权限；手机内置核心提供独立管理密钥，旧聊天身份保持不变，已撤销的管理密钥不会自动重建。

本批聊天流程已在真实核心和本机合成模型上验证：人格默认模型、世界书与记忆注入、消息记忆关联、草稿和短语隔离、逐项取消世界书、JSONL 下载、刷新持久化、来源失效以及删除当前配置。管理页的新增编辑、导入导出、回收恢复、部分保存失败重试与 320–1440 像素布局也已通过浏览器检查。原生密钥分槽和文件保存桥接已通过桌面测试；这些结果不代替 Android 真机验收。

## 工具与远程 MCP

连接后进入“更多 → 工具与 MCP”。管理密钥需要 `mcp` 权限，与聊天密钥分开保存；缺少权限时可直接返回连接设置补充。这里控制当前核心的工具和服务，变更会影响使用同一核心的其他会话。

工具页可按名称、描述或来源查找工具，查看是否允许调用；可修改的工具支持启用和停用。MCP 页支持远程 HTTP 服务的新增、编辑、连接检查、启停和删除。连接检查展示发现的工具，启用后可在工具页查看；配置保存成功不代表远程服务始终在线。

密钥与请求头不在列表中回显，编辑时凭据留空保留原值。手机界面不新增、编辑、检查或启用本地进程型 MCP；已有这类服务仅供查看、停用或删除。界面不恢复已撤下的本地专用桥。

本批仅包含工具与远程 MCP 管理。每次询问的审批、调用审计、MCP 导入导出与人格绑定、珍藏尚未包含，不代表整个 S4 已完成。没有构建新 APK，需使用本分支的前端和 Tillith 后端。

## Android 构建状态

手机基础核心使用 `mobile/native-python/mobile-requirements.txt`，保留聊天、人格、SQLite、内置插件、API 与附件依赖；上游完整服务端清单仍保存在 `requirements.txt`。外部聊天平台、Docker、FAISS 知识库索引与额外文档转换需要各自的依赖，不能因为插件能安装就假定它支持 Android。该精简环境已通过真实启动、消息与附件往返，以及关闭后的数据库持久化检查。

Capacitor 壳与 `mobile/native-python` 嵌入入口仍在集成。Python 核心涉及多个原生二进制依赖，需要可用于目标 Android ABI 的构建产物及实机或模拟器验证。当前没有已验收可用的 APK，桌面上的嵌入启动成功不能代替手机运行验收。

## 反向代理与长时间回复

服务端在 20 秒没有输出时发送 WebSocket `keepalive` 事件；客户端不把它写入消息或历史。nginx 需透传 WebSocket 升级头，并为长思考和工具调用留出读取时间：

```nginx
location / {
    proxy_pass http://127.0.0.1:6195;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 3600s;
    proxy_buffering off;
}
```

生产环境保留已有 TLS 配置。心跳不能恢复已经结束的生成，也不能绕过负载均衡器的连接总时长上限；仍需在实际反代环境验收。
